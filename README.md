# ことばポケット / ai-translator

iPhone・Chromebook向けの、日本語で使える多言語翻訳サイトです。HTML・CSS・JavaScriptのみで動き、GitHub Pagesで無料公開できます。ビルド、APIキー、有料API、外部AIサービスのアカウント登録は不要です。

## できること・できないこと

- テキストの入力・貼り付け、翻訳結果のコピー。クリップボードが使えない場合は、長押しや通常のコピー・貼り付けを使います。
- 外国語 → 日本語、日本語 → 設定した外国語。原文は自動判定または手動指定できます。
- 対応言語の選択肢：日本語、英語、中国語（簡体字・繁体字）、韓国語、スペイン語、フランス語、ドイツ語、イタリア語、ポルトガル語、ロシア語、アラビア語、ヒンディー語、タイ語、ベトナム語、インドネシア語。**選択肢にあっても、その端末のモデルが対応していなければ翻訳できません。**
- IndexedDBによる履歴の保存・検索・削除・再利用。**初期設定は保存オフ**。オンにすると成功した翻訳を最大200件保存し、それを超えた古い履歴は削除します。
- モデル画面、お気に入り・ピン留め。現在使えるエンジンは Chrome Translator だけです。「未導入」の候補を実行する機能はありません。
- 画像選択・プレビュー・削除。**OCRと画像翻訳は未実装**です。画像を翻訳したように見せる表示はありません。iPhoneのHEIC画像はJPEGなどに変換してから選んでください。
- 端末設定に連動するダークモード、手動切り替え、ホーム画面アイコン、PWA。

### 翻訳の対応状況

**iPhone SafariはChrome Translator APIに未対応のため、この版では実際の翻訳ができません。** iPhone版Chromeに切り替えても利用できるとは限りません。iPhoneでも入力・画像プレビュー・既存履歴などの画面は使えます。

Chromebookも、OS、Chromeのバージョン、ハードウェア、空き容量、管理者ポリシー、言語モデルの対応によって利用可否が異なります。新しいChromeを使い、サイトの案内を確認してください。Chromeが入っているだけで翻訳を保証するものではありません。

APIの有無と `Translator.availability()` を実行時に確認します。自動判定には別途 `LanguageDetector` が必要です。自動判定が使えない場合は「言語設定」で原文の言語を指定してください。

初回にブラウザがモデルをダウンロードする場合があります。その際は確認画面を表示します。通信量と空き容量を使用しますが、このサイトから利用料金を請求することはありません。ダウンロード失敗、未対応、判定失敗の場合はエラーを表示し、架空の翻訳で代用しません。

## 初めての公開手順（Chromebookのブラウザでできます）

まず、この作業の変更ファイルをGitHubへ保存します。この画面に「差分」「コミット」「PRを作成」などの操作があれば利用してください。GitHubへまだ送られていないファイルは、GitHubの画面には表示されません。

ブラウザでファイルを保存する場合：

1. 作業ファイル一式をダウンロードします（利用中の画面にダウンロード機能がある場合）。
2. GitHubの `st261508-collab/ai-translator` を開きます。
3. 「Add file」→「Upload files」で、`index.html`、`style.css`、`script.js`、`sw.js`、`manifest.webmanifest`、`icons`フォルダ、`tests`フォルダ、`README.md`をアップロードします。ZIPをそのまま置かず、解凍した中身を置きます。
4. 「Commit changes」で保存します。ブランチを作った場合はPRを作り、内容を確認して `main` にマージします。
5. リポジトリの一番上の階層に `index.html` と `icons` フォルダがあることを確認します。
6. リポジトリの「Settings」→「Pages」を開きます。設定を変更できる管理権限が必要です。
7. 「Build and deployment」の「Source」で **Deploy from a branch** を選びます。
8. 「Branch」を **main**、フォルダを **/(root)** にして「Save」を押します。
9. 数分待ち、Pagesに表示された公開先を開きます。通常は `https://st261508-collab.github.io/ai-translator/` です。これは公開予定のURLで、今回の作業で公開済みとは限りません。
10. iPhoneのSafariで開き、「共有」→「ホーム画面に追加」を選びます。iOSのバージョンで表示名・位置が変わる場合があります。

無料のGitHubプランでPagesを利用する場合、通常は公開リポジトリが必要です。非公開のコードや秘密情報がある場合は、確認せず公開設定へ変更しないでください。

### 初回の使い方

1. 「言語設定」で原文の言語を選びます。まずは自動判定より手動指定がおすすめです。
2. 日本語から翻訳する場合は、翻訳先の外国語も選びます。
3. 原文を入力、または「貼り付け」を押します。
4. 対応ブラウザでは「翻訳する」を押します。未対応の場合は画面に説明が表示されます。
5. 結果が出たら「コピー」を押します。
6. 履歴が必要なときだけ「翻訳履歴をこの端末に保存する」をオンにします。
7. 「履歴」で検索・再利用・削除ができます。保存をオフにしても過去の履歴は消えません。「すべて削除」で削除してください。

## データとプライバシー

- サイトに解析ツール、外部フォント、広告、外部翻訳APIへの送信処理はありません。入力文・画像はサイトから外部へアップロードしません。
- 個人情報・パスワード・APIキー・秘密情報は入力しないでください。履歴は暗号化された保管庫ではありません。
- オンにした履歴はこのサイト・ブラウザのIndexedDBだけに保存されます。言語・配色・モデルのお気に入り設定はlocalStorageに保存します。
- 画像は一時プレビューのみで、ページを閉じると失われます。Service Workerは画面ファイルだけをキャッシュし、文章や画像を保存しません。
- GitHub Pagesの配信やブラウザによる翻訳モデルの取得には通常の通信が発生します。
- サイトデータを消すと設定・履歴・オフラインキャッシュも消えます。端末間同期やバックアップはありません。プライベートブラウズや容量不足では保存できないことがあります。
- オフライン画面は初回オンライン読み込み後に利用できます。**オフライン画面が開いても、翻訳モデルが未取得・未対応なら翻訳はできません。**

## ファイル構成と今後の拡張

- `index.html`：日本語の画面、ダイアログ
- `style.css`：スマートフォン対応・ダークモード
- `script.js`：翻訳アダプター `engines`、言語判定、IndexedDB、モデル設定、画像プレビュー
- `manifest.webmanifest` / `sw.js` / `icons/`：PWA、画面キャッシュ、アイコン
- `tests/browser.cjs`：ブラウザ統合テスト

すべてリポジトリ基準の相対パスです。`/ai-translator/` に配置できます。ビルドやNode.jsは配信に不要です。

将来のTransformers.js導入は、ライセンス・配布元・モデル容量・メモリ・iPhoneでの速度を検証して `engines` にアダプターを追加します。OCRは画像のプレビュー処理と分けて追加します。複数AIの正規APIを追加する場合は、キーを静的ファイルやGitHubへ置かず、別途適切な認証・サーバー構成を検討する必要があります。今の版では接続しません。

画面ファイルを更新するときは `sw.js` の `CACHE` のバージョンも上げてください。新しいキャッシュは、更新取得後に古いタブをすべて閉じ、開き直すと有効になります。

## 開発者向け：実行・テスト

このクラウド環境では `/workspace/ai-translator` が作業ディレクトリです。公開には以下のコマンドは不要です。

```sh
# /workspace を配信し、Pagesと同じサブディレクトリ構成を検証
python3 -m http.server 4173 --bind 127.0.0.1 --directory /workspace
```

別のターミナルで：

```sh
cd /workspace/ai-translator
node --check script.js
node --check sw.js
node tests/browser.cjs
```

テストにはNode.js、Playwright、Chromiumが必要です。この環境に既存のものを利用しました。別環境でPlaywrightがなければ、アプリの依存関係を変えずに一時ディレクトリへ導入できます：

```sh
npm install --prefix /tmp/kotoba-tests --cache /tmp/kotoba-npm-cache playwright@1.58.2 --no-audit --no-fund
NODE_PATH=/tmp/kotoba-tests/node_modules CHROMIUM_PATH=/usr/bin/chromium node tests/browser.cjs
```

Chromiumが別の場所にある場合は `CHROMIUM_PATH`、テスト用配信先を変える場合は `TEST_BASE_URL` を指定します。

テストは未対応表示、スマートフォン幅、設定保持、画像プレビュー、クリップボード、履歴操作、翻訳失敗、ダウンロード中止、入力変更による結果破棄、PWA・オフラインを検証します。翻訳成功系は**テスト内だけの模擬API**で制御フローを検証し、実際の翻訳モデルの品質を保証しません。iPhone Safari実機、実際の翻訳モデル、GitHub Pages公開後の動作は別途確認が必要です。
